# metrics/

Schema for `metrics-log.csv`, the anonymized measurement log that
accompanies the workflow's cost evaluation. Data collection is in
progress; the file lands here when the measurements are published.

One row per task session:

| Column | Meaning |
|--------|---------|
| `task_id` | anonymized task identifier |
| `mode` | `doc-centric` (full hierarchy) or `ad-hoc` (prompt-only baseline) |
| `input_tokens` | tokens sent to the agent |
| `output_tokens` | tokens generated by the agent |
| `wall_time_min` | elapsed session time |
| `dev_active_min` | developer time actively spent (reviewing, answering, editing) |
| `clarifications` | agent questions answered by the developer |
| `rework_events` | correction rounds after first implementation |
| `outcome` | `accepted` / `accepted-with-fixes` / `rejected` |

Project and client names are never recorded; only counts and durations.
